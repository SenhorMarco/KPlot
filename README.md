# KPlot

Calculadora gráfica básica, escrita em C++, utilizando a biblioteca SDL para a parte gráfica e o header exprtk para leitura e manipulação das expressões matemáticas. Só colocar o diretório do executável no PATH.

Uso: kplot exp1 exp2 exp3 ... expn (sem espaço dentro das expressões)


![Multiplas funções](/prints/1.png?raw=true "Funções x^2, x^3 e sqrt(x) + 3")
Exemplo: kplot x^2 x^3 sqrt(x)+3

![Funções periódicas](/prints/2.png?raw=true "Função sen(x) + 1")
Exemplo: kplot sin(x)+1
