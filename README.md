# KPlot

Calculadora gráfica básica, escrita em C++, utilizando a biblioteca SDL para a parte gráfica e o header exprtk para leitura e manipulação das expressões matemáticas. 
Ao rodar o programa: Insirir lagura e altura (melhor 800x800), depois escrever as equações em x (SEM ESPAÇO (ler documentação da exprtk)). Ao terminar digite "fim".
